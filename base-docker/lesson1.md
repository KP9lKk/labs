## 1. Краткие теоретические сведения

### 1.1. Базовые понятия и терминология
**Docker** — платформа для разработки, доставки и запуска приложений в изолированных средах — контейнерах.

Основные понятия:
* **Image (Образ)** — шаблон «только для чтения» (Read-Only), содержащий все необходимые зависимости, библиотеки, код и конфигурационные файлы для запуска приложения.
* **Container (Контейнер)** — запущенный и изолированный экземпляр образа с доступом на запись (Read-Write слой).
* **Registry (Реестр)** — хранилище и сервис распространения готовых Docker-образов (например, публичный реестр Docker Hub).
* **Проброс портов (Port Mapping)** — механизм связывания порта хост-системы с портом внутри контейнера (`-p [порт_хоста]:[порт_контейнера]`) для обеспечения доступа к сервису из внешней сети.

### 1.2. Справка по командам Docker

Взаимодействие с Docker осуществляется через интерфейс командной строки (CLI):

* `docker pull [образ]` — скачивание образа из реестра на локальную машину.
* `docker run [флаги] [образ]` — создание и запуск нового контейнера на основе указанного образа.
  * Флаг `-d` (detached) — запуск контейнера в фоновом режиме.
  * Флаг `--name [имя]` — присвоение понятного имени контейнеру.
  * Флаг `-e [переменная=значение]` — передача переменных окружения (Environment Variables) внутрь контейнера.
  * Флаг `-p [порт_хоста]:[порт_контейнера]` — настройка проброса портов.
* `docker ps` — просмотр списка активных запущенных контейнеров (флаг `-a` выводит все контейнеры, включая остановленные).
* `docker exec -it [имя_контейнера] [команда]` — выполнение команды внутри запущенного контейнера в интерактивном режиме.
* `docker stop [имя_контейнера]` — остановка работающего контейнера.
* `docker rm [имя_контейнера]` — удаление остановленного контейнера.
* `docker logs [имя_контейнера]` — просмотр логов(журнал событий) контейнера.

### Задание 1. Загрузка образа, запуск PostgreSQL и работа через CLI

**Формулировка задачи:** Загрузить официальный образ СУБД PostgreSQL из реестра, развернуть контейнер с настройкой портов и переменных окружения, подключиться к базе данных через консоль и сформировать структуру таблиц.

#### Техническое задание:

1. Выполнить загрузку образа СУБД PostgreSQL:
   * **Image:** `postgres:latest` (из Docker Hub).
2. Запустить контейнер со следующими параметрами:
   * Имя контейнера: `my-postgres`.
   * Переменная окружения `POSTGRES_PASSWORD`: `mysecretpassword`.
   * **Проброс портов:** связать порт `5432` хоста с портом `5432` контейнера.
   * Режим запуска: фоновый (`-d`).
3. Подключиться к контейнеру через `docker exec` и утилиту `psql`.
4. Выполнить создание базы данных `dev_db`, таблицы `users` и добавить 2 тестовые записи.

#### Требуемый формат команд и вывода:

```bash
# Пример команды запуска
docker run -d --name my-postgres -e POSTGRES_PASSWORD=mysecretpassword -p 5432:5432 postgres

# Проверка статуса
docker ps

```

```text
=== ВНУТРИ PSQL ===
CREATE DATABASE dev_db;
\c dev_db
CREATE TABLE users (id SERIAL PRIMARY KEY, name VARCHAR(50));
INSERT INTO users (name) VALUES ('Alice'), ('Bob');
SELECT * FROM users;

 id | name 
----+-------
  1 | Alice
  2 | Bob

```

### Задание 2. Подключение к контейнеру из внешнего графического клиента (DBeaver)

**Формулировка задачи:** Проверить доступность СУБД PostgreSQL, запущенной в Docker-контейнере, настроив подключение из стороннего графического клиента DBeaver с использованием проброшенного порта.

#### Техническое задание:

1. Открыть GUI-клиент **DBeaver** на локальной машине.
2. Создать новое соединение с типом базы данных **PostgreSQL**.
3. Указать следующие параметры подключения:
* **Host:** `localhost` (или `127.0.0.1`)
* **Port:** `5432`
* **Database:** `dev_db` (созданная в Задании 1)
* **Username:** `postgres`
* **Password:** `mysecretpassword`


4. Выполнить проверку соединения (кнопка *Test Connection*).
5. Открыть SQL-редактор в DBeaver и написать SQL-запрос для извлечения данных из таблицы `users`.
6. Вставить новую запись в таблицу `users` через DBeaver и проверить изменения.

#### Требуемый формат SQL-запросов и результата:

```sql
-- Проверка существующих записей
SELECT * FROM users;

-- Добавление новой записи через DBeaver
INSERT INTO users (name) VALUES ('Charlie');

-- Итоговая проверка
SELECT * FROM users ORDER BY id;

```

id | name
---+--------

 2 | Bob
