# Краткая справка по Linux-командам
---
## 1. `mkdir` — создание директорий

**Описание:** создаёт одну или несколько директорий.

**Синтаксис:**
```bash
mkdir [опции] имя_директории
```
- `-p` — создать всю цепочку директорий, если родительских не существует (не выдаёт ошибку, если директория уже есть).

**Пример:**
```bash
mkdir ~/pgdata_bind
mkdir -p /var/lib/postgresql/data/conf.d
```

**Упражнения:**
1. Создайте директорию `~/lab_docker`.
2. Создайте цепочку `~/lab_docker/postgres/conf.d` одной командой.
3. Повторно выполните п.2 — убедитесь, что ошибки нет.

## 2. `rm` — удаление файлов и директорий

**Описание:** удаляет файлы и директории.

**Синтаксис:**
```bash
rm [опции] путь
```
- `-r` — рекурсивно (для директорий);
- `-f` — без запроса подтверждения.

**Пример:**
```bash
rm -rf ~/pg_config_lab
rm file.txt
```

**Упражнения:**
1. Удалите файл `~/lab_docker/test.txt`.
2. Удалите директорию `~/lab_docker` со всем содержимым без подтверждения.
3. Объясните, почему `rm -rf /` опасна.

## 3. `echo` — вывод текста / запись в файл

**Описание:** выводит строку на экран или перенаправляет её в файл.

**Синтаксис:**
```bash
echo "текст"
echo "текст" >> файл    # добавить в конец
echo "текст" > файл     # перезаписать
```

**Пример:**
```bash
echo "work_mem = '24MB'" >> /var/lib/postgresql/data/conf.d/work_mem.conf
echo "\timing on" >> ~/.psqlrc
```

**Упражнения:**
1. Выведите `Hello, PostgreSQL!`.
2. Запишите `work_mem = '32MB'` в файл `~/lab_docker/postgres/conf.d/work_mem.conf`.
3. Допишите туда же `maintenance_work_mem = '256MB'`.

## 4. `export` — установка переменных окружения

**Описание:** задаёт переменную окружения в текущей сессии.

**Синтаксис:**
```bash
export ИМЯ=значение
```

**Пример:**
```bash
export PGHOST=localhost
export PGPORT=5432
export PGUSER=postgres
export PGPASSWORD=mysecretpassword
```

**Упражнения:**
1. Установите `PGHOST`, `PGPORT`, `PGUSER`, `PGPASSWORD`, `PGDATABASE`.
2. Проверьте `echo $PGUSER`.
3. Подключитесь к psql без параметров (если установлен).

## 10. `awk` — построчный анализатор текста

**Описание:** утилита и мини-язык для обработки текста. Читает вход **построчно**, разбивает строку на **поля** и выполняет действия.

**Как работает:**
- По умолчанию поля разделяются пробелами и табуляцией.
- Поля: `$1`, `$2`, `$3`, … `$NF` (последнее поле).
- `$0` — вся строка целиком.
- Свой разделитель задаётся через `-F`.

**Синтаксис:**
```bash
awk 'шаблон {действие}' файл
команда | awk '{действие}'
```

**Примеры:**
```bash
echo "one two three" | awk '{print $2}'
# two

free -m | grep Mem | awk '{print $2}'
# объём RAM в МБ

awk -F: '{print $1}' /etc/passwd
# имена пользователей

awk '{print $1, $3}' file.txt
# первое и третье поля

awk '$3 > 100 {print $1}' file.txt
# первое поле, если третье > 100
```

**Полезные переменные:**
- `NR` — номер текущей строки;
- `NF` — число полей в строке;
- `FS` — разделитель полей.

**Упражнения:**
1. Выведите второе поле из строки `"a b c d"`.
2. Получите объём использованной памяти: `free -m | grep Mem | awk '{print $3}'`.
3. Создайте `test.txt` с тремя строками и выведите первую и последнюю через `awk 'NR==1 || NR==3'`.
4. Передайте `nproc` в `awk`: `nproc | awk '{print "CPU:", $1}'`.

## 11. Оператор `|` — конвейер (pipe)

**Описание:** передаёт **стандартный вывод** (stdout) одной команды на **стандартный ввод** (stdin) другой. Позволяет строить цепочки обработки.

**Синтаксис:**
```bash
команда1 | команда2
команда1 | команда2 | команда3
```

**Примеры:**
```bash
docker logs pg-config | grep ERROR
free -m | grep Mem
free -m | grep Mem | awk '{print $2}'
ls -la | grep .psqlrc
```

**Важно:**
- `|` передаёт только stdout. Ошибки (stderr) идут на экран.
- Чтобы передать и ошибки: `команда 2>&1 | grep ...`.
- Не путать:
    - `>` — записать stdout в файл (перезаписать);
    - `>>` — дописать stdout в файл;
    - `|` — передать stdout другой команде.

**В SQL (PostgreSQL):**
- `|` — побитовое ИЛИ;
- `||` — конкатенация строк;
- в `\pset fieldsep '|'` символ `|` — просто разделитель столбцов.

**Упражнения:**
1. Выведите только строку с `Mem` из `free -m`.
2. Из этой строки получите второе поле через `awk`.
3. Найдите `.psqlrc` в `ls -la ~`.
4. Передайте `docker logs pg-config` в `grep ERROR` и объясните, что произошло.

## 12. `free` — информация о памяти

**Описание:** показывает использование оперативной памяти.

**Синтаксис:**
```bash
free [опции]
```
- `-m` — в мегабайтах.

**Пример:**
```bash
free -m
docker exec pg-config free -m
```

**Упражнения:**
1. Выполните `free -m` и определите общий объём RAM.
2. Сравните с `free -h`.
3. Сравните с `docker exec pg-config free -m`.
