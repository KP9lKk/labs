### Лабораторная работа №1: Исследование превращения текста программы на Kotlin в байт-код JVM



#### 1. Входные данные (Контекст)

Используется среда разработки **IntelliJ IDEA** с установленным комплектом средств разработки **JDK (Java Development Kit)**. Задача — сформировать исходный файл `Lab1.kt`, скомпилировать его и исследовать полученный байт-код JVM, чтобы понять, как тексты программ превращаются в инструкции виртуального процессора.

---

#### 2. Справка по трансляции кода и байт-коду JVM

##### Общий обзор цепочки выполнения

* **Исходный код (`.kt`):** Текстовый файл в кодировке UTF-8/ASCII, состоящий из байтов, представляющих символы языка Kotlin.


* **Компилятор (`kotlinc`):** Транслирует исходный текст программы в промежуточный байт-код, сохраняемый в бинарных `.class` файлах.


* **Виртуальная машина JVM:** Стековая виртуальная машина, которая читает байт-код и переводит его в инструкции физического процессора.



##### Команды байт-кода JVM для работы со стеком

В отличие от регистровых процессоров, JVM использует стековую модель для вычисления выражений:

```text
// 1. BIPUSH / ICONST n: Загрузка целого числа n на вершину стека вычислений
BIPUSH 5

// 2. IADD: Извлечение двух верхних чисел из стека, их сложение и запись результата обратно в стек
IADD

// 3. INVOKEVIRTUAL: Вызов метода (например, печати в консоль System.out.println)
INVOKEVIRTUAL java/io/PrintStream.println (I)V

```

#### 3. Требования к лабораторной работе (`Lab1.kt`)

Выполнить **4 практических шага** по исследованию кода:

1. **Задание 1 (Создание исходного кода):** Написать в файле `Lab1.kt` функцию `main()`, объявляющую переменные `a = 5`, `b = 10`, рассчитывающую их сумму в переменной `sum` и выводящую результат на экран.


2. **Задание 2 (Генерация байт-кода):** Скомпилировать проект и открыть окно просмотра байт-кода с помощью меню **Tools --> Kotlin --> Show Kotlin Bytecode**.


3. **Задание 3 (Анализ инструкций):** Найти в сгенерированном байт-коде инструкции загрузки констант (`BIPUSH` / `ICONST`) и инструкцию сложения (`IADD`).


4. **Задание 4 (Декомпиляция в Java):** Нажать кнопку **Decompile** в окне просмотра байт-кода и проанализировать полученный эквивалентный код на Java.
