#### 2. Справка по двоичной арифметике, дополнительному коду и try-catch

##### Формат дополнительного кода

Для представления отрицательных целых чисел в памяти используется дополнительный код (Two's Complement).

* **Знаковый бит:** Самый старший (левый) бит. `0` — число positive (+), `1` — negative (-).
* **Преобразование $X --> -X$:** 
  1. Побитовая инверсия `inv()` (замена всех `0` на `1` и `1` на `0`).
  2. Прибавление `1` к полученному значению.

##### Механизм переполнения (Overflow)

Разрядная сетка примитивных типов (`Byte` — 8 бит, `Short` — 16 бит, `Int` — 32 бита) ограничена. При прибавлении единицы к максимальному положительному числу старший бит переноса попадает в знаковый разряд, превращая число в минимальное отрицательное.

##### Обработка исключений переполнения (`try-catch`)

В Kotlin (как и в Java) обработка ошибок выполнена через конструкцию `try-catch` (аналог `try-except` из Python):

```kotlin
try {
    // Код, в котором может возникнуть ошибка (например, переполнение)
    val result = Math.addExact(a, b)
    println("Результат: $result")
} catch (e: ArithmeticException) {
    // Блок выполняется, если произошло переполнение разрядной сетки
    println("Перехвачена ошибка переполнения: ${e.message}")
}

```
