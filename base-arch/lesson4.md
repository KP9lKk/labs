#### 2. Справка по архитектурам: Регистры vs Стек

##### Аппаратный процессор (Регистровая модель Фон-Неймана)
Процессор выполняет команды напрямую над ячейками памяти (**RAM**) и внутренними сверхбыстрыми ячейками — **регистрами** (например, Аккумулятор `A`, регистры `X`, `Y`).
* `LDA #val` (Load Accumulator) — загрузить значение в аккумулятор `A`.
* `ADC #val` (Add with Carry) — прибавить значение к содержимому аккумулятора `A`.
* `STA addr` (Store Accumulator) — сохранить значение из аккумулятора в ячейку памяти.

##### Виртуальная машина JVM (Стековая модель)
JVM не завязывается на конкретные регистры процессора. Все операции выполняются внутри **Stack Frame**:
* **Local Variable Table:** Хранит аргументы и объявленные переменные.
* **Operand Stack:** Вычислительный LIFO-стек («черновик»).
* `ILOAD x` / `ISTORE x` — обмен данными между таблицей переменных и стеком.
* `IADD` / `IMUL` / `ISUB` — забирают аргументы с вершины стека и возвращают результат.
