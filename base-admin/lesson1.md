# Лабораторная работа №1: Развертывание PostgreSQL 16 в Docker и кастомизация среды psql

#### 1. Входные данные (Контекст)

Данная лабораторная работа открывает практический блок курса по администрированию баз данных. Задача — развернуть СУБД PostgreSQL 16 в изолированном Docker-контейнере, настроить параметры инициализации кластера (переменную `PGDATA` и контрольные суммы страниц), сконфигурировать пользовательскую среду интерактивного терминала `psql` через файл `~/.psqlrc` и создать базовую структуру для хранения данных о карточках Покемонов (Pokémon TCG).

---

#### 2. Справка по инструментам и синтаксису

##### Развертывание и инициализация в Docker

Официальный Docker-образ `postgres:16` автоматически инициализирует кластер баз данных при первом запуске. Для управления поведением инициализации используются переменные окружения:

* **`POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB`:** Задают учетную запись суперпользователя и имя первоначальной базы данных.
* **`POSTGRES_INITDB_ARGS`:** Позволяет передать специфические флаги утилите `initdb`. Для защиты от повреждений данных на диске включается расчет контрольных сумм страниц (`-k` или `--data-checksums`).

##### Конфигурация psql и метакоманды

При старте клиент `psql` автоматически считывает файл `~/.psqlrc` из домашнего каталога. Это позволяет настроить поведение сеанса:

* **`\setenv PSQL_PAGER 'less -XS'`:** Управление прокруткой вывода без очистки экрана и без разрыва длинных строк.
* **`\set PROMPT1 '%n@%/%R%x%# '`:** Кастомизация формата приглашения ввода (`user@dbname=>`).
* **`\timing on`:** Автоматический замер времени выполнения SQL-запросов в миллисекундах.
* **`\set <имя> '<SQL_запрос>'`:** Создание пользовательских переменных для вызова частых запросов через синтаксис `:<имя>`.

#### 3. Требования к выполнению работы

Выполнить последовательность шагов и сформировать итоговый файл отчета/скрипта `lab1_install_psql.sql`:

1. **Шаг 1 (Docker):** Развернуть контейнер `johto-tcg-server` на базе `postgres:16` с пользователем `professor_elm`, паролем `totodile_secret`, базой `johto_db`, включенными контрольными суммами (`POSTGRES_INITDB_ARGS="-k"`) и пробросом порта `5433:5432`.
2. **Шаг 2 (Кастомизация psql):** Внутри контейнера создать файл `~/.psqlrc`, настроив `PSQL_PAGER`, `PROMPT1`/`PROMPT2`, `\timing on` и переменную `find_starter` для поиска карт с `hp >= 45`.
3. **Шаг 3 (Инспекция параметров):** Подключиться к `johto_db` через `psql`, проверить приглашение строки, с помощью `\conninfo` получить данные подключения, а запросами `SHOW data_checksums;` и `SHOW data_directory;` подтвердить активный статус контрольных сумм и путь к `PGDATA`.
4. **Шаг 4 (DDL/DML):** В базе `johto_db` создать схему `starter_set` и таблицу `pokemon_cards` (`card_id`, `name`, `hp`, `card_number`, `rarity`). Наполнить её 3 картами (Chikorita 45 HP, Cyndaquil 39 HP, Totodile 50 HP).
5. **Шаг 5 (Проверка работы переменной):** Выполнить сохраненную команду `:find_starter`, убедиться в корректности выборки и отображении времени выполнения запроса.
