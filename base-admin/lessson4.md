#### 2. Справка по инструментам и синтаксису

##### Связи между таблицами системного каталога

* **`pg_class`:** Содержит метаданные об отношениях (таблицах, индексах, представлениях). `relkind = 'r'` отвечает обычным таблицам.
* **`pg_attribute`:** Хранит атрибуты (столбцы). Привязывается к `pg_class` по условию `attrelid = pg_class.oid`.
* **`pg_type`:** Содержит информацию о типах данных. Привязывается к `pg_attribute` по условию `atttypid = pg_type.oid`.
* **`'schema.table'::regclass`:** Удобный способ получить OID таблицы без явного написания подзапросов.

#### 3. Требования к выполнению работы

Сформировать скрипт `lab4_system_catalog.sql` со следующими шагами:

1. **Шаг 1 (Создание структуры):** 
   * В базе данных `johto_db` в схеме `starter_set` создать таблицу `rare_deck` со столбцами:
     * `deck_id` (`INT GENERATED ALWAYS AS IDENTITY PRIMARY KEY`).
     * `deck_name` (`VARCHAR(100)`).
     * `release_year` (`INT`).
     * `temp_code` (`TEXT`).
2. **Шаг 2 (Запрос метаданных таблицы через `pg_class`):**
   * Написать SQL-запрос к `pg_class`, вычисляющий OID таблицы `starter_set.rare_deck`, количество пользовательских столбцов (`relnatts`), количество страниц на диске (`relpages`) и OID её TOAST-таблицы (`reltoastrelid`).
3. **Шаг 3 (Детальная инспекция столбцов):**
   * Написать соединительный запрос (`JOIN`) между `pg_attribute` и `pg_type`, который выводит для таблицы `starter_set.rare_deck`:
     * Порядковый номер столбца (`attnum`).
     * Имя столбца (`attname`).
     * Название типа данных (`typname`).
     * Флаг запрета `NULL` (`attnotnull`).
     * Режим хранения TOAST (`attstorage`).
   * Отфильтровать системные столбцы (`attnum > 0`).
4. **Шаг 4 (Исследование логического удаления):**
   * Удалить столбец `temp_code` командой `ALTER TABLE starter_set.rare_deck DROP COLUMN temp_code;`.
   * Повторно выполнить запрос к `pg_attribute` (без фильтра по `attisdropped`) и зафиксировать, как СУБД отображает удаленный столбец (`attisdropped = true`, измененное имя `attname`).
5. **Шаг 5 (Сравнение с `information_schema`):**
   * Написать эквивалентный запрос к представлению `information_schema.columns` для вывода списка действующих столбцов таблицы `rare_deck` и сравнить его с результатом из `pg_attribute`.
