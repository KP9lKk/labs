---

#### 2. Справка по инструментам и синтаксису

##### Схемы и разрешающий путь `search_path`

* **`CREATE SCHEMA schema_name;`** — создание нового пространства имен внутри текущей базы данных.
* **`\dn`** — метакоманда `psql` для просмотра списка всех доступных схем.
* **`SHOW search_path;`** — вывод текущего порядка поиска схем при адресации к объектам.
* **`SET search_path = schema1, schema2;`** — установка порядка поиска для текущей сессии.
* **`ALTER DATABASE dbname SET search_path = schema1, schema2;`** — зафиксировать приоритет схем для базы данных (применяется при каждом новом подключении).

Сформировать скрипт `lab3_schemas.sql` со следующими шагами:

3. **Шаг 3 (Работа с `search_path` в сессии):**

   * Убедиться с помощью `SHOW search_path;`, что параметр применился автоматически.
5. **Шаг 5 (Инспекция системного каталога):**
