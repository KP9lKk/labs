# Раздел 5.1. Практикум и списки задач: Коллекции и операции над ними в Pokémon TCG

## 1. Сводный список ключевых понятий раздела

* **Типы коллекций в Kotlin:**

  * `List<T>` — неизменяемый (read-only) упорядоченный список с доступом по индексу и поддержкой дубликатов.

  * `MutableList<T>` — изменяемый список, поддерживающий добавление (`add`), удаление (`remove`, `removeAt`) и обновление элементов.

  * `Set<T>` — неизменяемое множество уникальных элементов (автоматически игнорирует повторы).

  * `MutableSet<T>` — изменяемое множество с методами `add` и `remove`.

  * `Map<K, V>` — неизменяемый словарь пар «ключ–значение» с уникальными ключами.

  * `MutableMap<K, V>` — изменяемый словарь с возможностью перезаписи и добавления пар.

* **Основные функциональные операции над коллекциями:**

  * `filter { ... }` — отбор элементов, удовлетворяющих заданному условию.

  * `map { ... }` — преобразование каждого элемента коллекции в новое значение.

  * `sortedBy { ... }` — сортировка элементов по заданному полю или критерию.

  * `count { ... }` — подсчёт количества элементов, соответствующих условию.

  * `sumOf { ... }` — вычисление суммы числовых значений, полученных из элементов.

  * `joinToString(...)` — объединение элементов коллекции в единую строку с разделителями.
