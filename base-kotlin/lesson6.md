### 1. Краткие теоретические сведения

Функции в Kotlin объявляются с помощью ключевого слова `fun`. Они позволяют структурировать код, избегать дублирования и изолировать логику.

#### **A. Функции без возвращаемого значения (`Unit`) и с возвратом**

Если функция ничего не возвращает, её тип возвращаемого значения — `Unit` (его можно опускать). Если функция возвращает значение, тип указывается через двоеточие после списка параметров.

```kotlin
// Функция без возвращаемого значения (Unit опущен)
fun printPokemonInfo(name: String, hp: Int) {
    println("Покемон $name имеет $hp HP")
}

// Функция с возвращаемым значением Int
fun calculateDamage(baseDamage: Int, bonus: Int): Int {
    val total = baseDamage + bonus
    return total
}
```

#### **Б. Краткая запись функций (Single-expression functions)**

Если тело функции состоит из одного выражения, можно опустить фигурные скобки `{}` и оператор `return`, указав выражение через знак `=` (тип возвращаемого значения выводится автоматически).

```kotlin
// Краткая запись (Single-expression)
fun isFainted(hp: Int): Boolean = hp <= 0

// Однострочная функция без явного указания типа
fun formatCardName(name: String) = "Карта: ${name.trim().uppercase()}"
```

#### **В. Параметры по умолчанию и именованные аргументы**

Параметрам функции можно задавать значения по умолчанию. При вызове такие аргументы можно опускать или передавать в произвольном порядке, используя **именованные аргументы**.

```kotlin
fun attack(
    attacker: String,
    target: String = "Дикий покемон",
    damage: Int = 10,
    isCritical: Boolean = false
) {
    val finalDamage = if (isCritical) damage * 2 else damage
    println("$attacker атакует $target и наносит $finalDamage урона!")
}

// Варианты вызова:
attack("Pikachu") // Используются значения по умолчанию для target, damage, isCritical
attack("Charmander", "Squirtle", 20) // Позиционные аргументы
attack("Pikachu", isCritical = true, damage = 15) // Именованные аргументы
```

#### **Г. Функции высшего порядка (лямбды)**

Функция может принимать другую функцию в качестве параметра (функция высшего порядка) или возвращать её.

```kotlin
// Функция высшего порядка: принимает функцию modifier в качестве параметра
fun applyBuff(baseStat: Int, modifier: (Int) -> Int): Int {
    return modifier(baseStat)
}

fun main() {
    // Вызов с передачей лямбда-выражения
    val boostedHp = applyBuff(100) { hp -> hp + 50 } // 150
}
```
