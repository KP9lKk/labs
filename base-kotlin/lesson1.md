## 1. Краткие теоретические сведения

### 1.1. Переменные и типы данных

**Переменная** — поименованная область оперативной памяти, предназначенная для хранения данных определенного типа.

В Kotlin используется строгая статическая типизация с поддержкой автоматического вывода типов (`Type Inference`). Вы можете указывать тип явно через двоеточие или позволить компилятору определить его самостоятельно по присвоенному значению:

```kotlin
// Явное указание типа (рекомендуется для учебных задач):
val trainerName: String = "Эш Кетчум"
var badgesCount: Int = 8

// Автоматический вывод типов (стандарт в индустрии):
val trainerName = "Эш Кетчум" // Компилятор сам определяет тип String
var badgesCount = 8            // Компилятор сам определяет тип Int

```

**Ключевые слова объявления:**

* **`val`** (value) — переменная только для чтения (*read-only*). Значение нельзя изменить после инициализации.
* **`var`** (variable) — изменяемая переменная. Значение можно переопределять в процессе работы программы.

**Основные базовые типы:**

* `String` — текстовые строки в двойных кавычках.
* `Int` — 32-разрядные целые числа со знаком.
* `Double` — вещественные числа с плавающей запятой двойной точности.
* `Boolean` — логический тип, принимающий значения `true` или `false`.

### 1.2. Консольный ввод/вывод

Для работы с консолью применяются встроенные функции:

* `println()` — выводит значение в консоль с последующим переходом на новую строку.


* `print()` — выводит значение без перехода на новую строку.


* `readln()` — приостанавливает выполнение программы и считывает введенную пользователем строку до нажатия Enter. Возвращает тип `String`.



Для форматирования вывода применяются **шаблоны строк** (String Templates) с символом `$`:

```kotlin
val title = "Параметр"
val value = 10
println("Название: $title, Значение: $value")
// Внутри фигурны скобок ${} можно выполнять простые выражения:
println("Следующий уровень: ${value + 1}")

```

## 2. Порядок выполнения работы

Работа состоит из двух последовательных этапов. Все задания выполняются в рамках одного проекта в файле `Main.kt`.

### Задание 1. Объявление переменных и статический вывод данных

**Формулировка задачи:** Создать переменные, описывающие характеристики тренера покемонов, и выдать сформированную структуру данных в консоль.

#### Техническое задание:

1. Объявить и инициализировать в коде следующие переменные:
* `trainerName` (тип `String`) — значение: `"Эш Кетчум"`.


* `homeRegion` (тип `String`) — значение: `"Канто"`.


* `badges` (тип `Int`) — значение: `8`.


* `pokedexCount` (тип `Int`) — значение: `150`.




2. Сформировать консольный вывод информации с использованием механизмов шаблонов строк (`$`).



#### Требуемый формат вывода:

```text
=== БАЗА ДАННЫХ ТРЕНЕРОВ ===
Тренер: Эш Кетчум
Родной регион: Канто
Значков: 8 | Покемонов в Покедексе: 150

```

---

### Задание 2. Интерактивный ввод и динамическое формирование документов

**Формулировка задачи:** Модифицировать алгоритм для обеспечения ввода данных пользователем с клавиатуры и динамической генерации итоговой лицензии.

#### Техническое задание:

1. Реализовать последовательный запрос параметров у пользователя:
* Имя инспектора (`inspectorName`) — тип `String`.


* Имя тренера (`trainerName`) — тип `String`.


* Стартовый покемон (`starterPokemon`) — тип `String`.


* Название следующего стадиона (`targetGym`) — тип `String`.




2. Для организации приглашений к вводу использовать функцию `print()`.


3. Считать введенные значения с помощью `readln()`.


4. Вывести итоговую лицензию тренера с использованием форматированного вывода.



#### Требуемый формат диалога и вывода:

```text
Введите имя инспектора: Профессор Оук
Введите имя тренера: Ред
Введите стартового покемона: Чармандер
Введите целевой стадион: Вермилион Сити

****************************************
ЛИЦЕНЗИЯ ТРЕНЕРА
Инспектор: Профессор Оук
Тренер: Ред [Стартер: Чармандер]
Следующая цель: Стадион Вермилион Сити
****************************************

```
