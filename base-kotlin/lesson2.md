## 1. Краткие теоретические сведения

### 1.1. Приведение типов данных (Casting)

В Kotlin используется строгая типизация — компилятор не выполняет неявное расширение типов (например, `Int` автоматически не превращается в `Double`).

Так как функция `readln()` всегда возвращает текстовую строку (тип `String`), для математических расчетов введенные данные необходимо явно преобразовывать к нужным числовым типам:

* `.toInt()` — преобразует строку или число в целое число `Int`.
* `.toDouble()` — преобразует строку или число в вещественное число `Double`.
* `.toString()` — преобразует любой тип в строковое представление `String`.

```kotlin
val inputString: String = readln() // Пользователь ввел "60"
val healValue: Int = inputString.toInt() // Значение 60 с типом Int

```

### 1.2. Математические операции

В Kotlin поддерживаются стандартные бинарные и унарные математические операторы:

* **Базовые операции:** `+` (сложение), `-` (вычитание), `*` (умножение), `/` (деление), `%` (остаток от деления).
* **Особенности деления:**
* При делении двух целых чисел (`Int / Int`) результат округляется в меньшую сторону с отбрасыванием дробной части (`7 / 2` даст `3`).
* Для получения точного результата с плавающей точкой хотя бы один из операндов должен иметь тип `Double` (`7.0 / 2` или `7.toInt().toDouble() / 2` даст `3.5`).


* **Составное присваивание:** `+=`, `-=`, `*=`, `/=`.
* **Инкремент и декремент:** `++` (увеличение переменной на 1), `--` (уменьшение переменной на 1).

* Вычислить остаток от деления номера хода на 2 (`val turnCheck = currentTurn % 2`).
