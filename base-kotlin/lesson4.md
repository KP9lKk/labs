## 1. Краткие теоретические сведения
Циклы позволяют многократно выполнять один и тот же блок кода. В Kotlin существует три основных вида циклов:
## A. Цикл while (с предусловием)
Выполняется до тех пор, пока истинно условие. Если условие ложно изначально, тело цикла не выполнится ни разу.
```kotlin
var cardsInDeck = 5
while (cardsInDeck > 0) {
println("Берем карту. Осталось в колоде: ${--cardsInDeck}")
}
```
## Б. Цикл do-while (с постусловием)
Сначала выполняет тело цикла, а затем проверяет условие. Гарантирует минимум одно выполнение блока кода. Идеально подходит для валидации консольного ввода пользователя.
```kotlin
var input: Int 
do {
print("Введите положительное число: ")
input = readln().toInt()
} while (input <= 0)
```

## В. Цикл for и диапазоны (Ranges)
Используется для перебора фиксированных последовательностей чисел (интервалов) или коллекций.
```kotlin
val range = 1..5               // 1, 2, 3, 4, 5 (включая границы)
val exclusive = 1 until 5      // 1, 2, 3, 4 (верхняя граница исключена)
val countdown = 5 downTo 1     // 5, 4, 3, 2, 1 (обратный порядок)
val stepped = 1..10 step 2     // 1, 3, 5, 7, 9 (шаг равен 2)
for (i in range) {
println("Итерация $i")
}
```
## Г. Операторы управления циклом

* break — немедленно прерывает выполнение всего цикла.
* continue — завершает текущий шаг и переходит к следующей итерации цикла.

## 2. Порядок выполнения работы
Напишите программу на языке Kotlin (Main.kt), симулирующую пошаговые циклические механики карточной игры:
## Часть 1. Набор стартовой руки (Цикл while)

1. Объявите мутабельные переменные: deckSize (изначально 60) и cardsInHand (изначально 0).
2. Запросите у пользователя через консоль количество карт, которое нужно взять в начале матча (targetDrawInput).
3. С помощью цикла while промоделируйте поочередный добор карт по одной за итерацию.
4. На каждом шаге цикла:
* Увеличивайте количество карт в руке (cardsInHand++).
  * Уменьшайте размер колоды (deckSize--).
  * Выводите лог: "[ДОБОР] Взята карта №... В руке: ... карт, в колоде осталось: ..."

## Часть 2. Гарантированная валидация ввода энергии (Цикл do-while)

1. По правилам игры стоимость атаки не может быть отрицательной. Программа должна гарантированно запросить ввод и не пропустить пользователя дальше, пока он не введет корректное число.
2. Используйте цикл do-while для циклического запроса ввода.
3. Внутри цикла:
* Запросите у пользователя число: "Сколько энергии требует сбросить атака? ".
  * Считайте строку и приведите к Int.
  * Если число некорректно (меньше 0), выведите предупреждение: "[ОШИБКА] Стоимость атаки не может быть отрицательной! Попробуйте снова."
4. Условие завершения цикла: продолжать итерации, пока введенное число меньше 0.

## Часть 3. Раунды автоматического боя (Цикл for и break/continue)

1. Считайте текущее здоровье Покемона-противника (enemyHpInput).
2. Напишите цикл for для симуляции 10 раундов боя (диапазон 1..10). Переменная цикла должна называться round.
3. На каждом раунде (итерации):
* Проверка на "особый" раунд (continue): Если раунд четный (round % 2 == 0), на покемона действует эффект защиты. Выведите лог "[Эффект Защиты] Раунд пропускается." и примените оператор continue до нанесения урона.
  * Нанесение урона: В нечетных раундах уменьшайте enemyHp на фиксированные 25 единиц. Выводите лог раунда: "Раунд $round: Нанесено 25 урона. У противника осталось $enemyHp HP."
  * Проверка на нокаут (break): Если enemyHp стало меньше или равно 0, выведите сообщение "Покемон противника упал без сил! Прерываем бой." и немедленно остановите цикл с помощью break.
