## Тема: Управляющие конструкции (`if-else`, `when`) и моделирование состояний в Pokémon TCG

**Цель работы:** Освоить работу с условным оператором `if-else` и многопутевым ветвлением `when` как в классическом формате (выполнение действий), так и в формате выражений (запись результата ветвления напрямую в переменную `val`).

---

### 1. Краткие теоретические сведения

Управляющие конструкции `if-else` и `when` в Kotlin могут использоваться в двух принципиально разных режимах:

#### **A. Классические управляющие инструкции (Statements)**

Используются, когда нужно выполнить определенный блок кода или вывести текст в зависимости от условий.

```kotlin
// --- Классический if-else ---
if (hp <= 0) {
    println("Покемон нокаутирован!")
} else {
    println("Покемон в строю.")
}

// --- Классический if с несколькими ветками ---
if (energy == 0) {
    println("Нет энергии")
} else if (energy < 3) {
    println("Мало энергии")
} else {
    println("Энергии достаточно")
}

// --- Классический when (выполнение команд) ---
when (cardType) {
    "Energy" -> println("Прикрепляем карту энергии")
    "Trainer" -> println("Применяем эффект карты Тренера")
    "Pokemon" -> println("Выводим Покемона на скамью")
    else -> println("Неизвестный тип карты")
}

```

#### **Б. Условные выражения (Expressions)**

Используются, когда результат ветвления нужно сразу сохранить в переменную `val` или `var`. При таком подходе ветка `else` **обязательна**, а значением переменной становится **последняя строка** выполненного блока.

```kotlin
// --- Выражение if-else (однострочное) ---
val status = if (hp > 0) "Активен" else "Нокаут"

// --- Выражение if-else (многострочный блок) ---
val finalDamage = if (isCritical) {
    println("Критический удар!") // Выполнится действие
    baseDamage * 2              // Это значение запишется в finalDamage
} else {
    println("Обычная атака")     // Выполнится действие
    baseDamage                  // Это значение запишется в finalDamage
}

// --- Выражение when по значению ---
val multiplier = when (element) {
    "Fire" -> 1.5
    "Water" -> 2.0
    "Grass" -> 1.2
    else -> 1.0 // Обязательный else!
}

// --- Безаргументное выражение when (проверка условий и диапазонов) ---
val healthCategory = when {
    hp == 0 -> "Нокаут"
    hp in 1..20 -> "Критическое состояние"
    hp in 21..70 -> "Поврежден"
    else -> "Отличное состояние"
}

```

### 2. Порядок выполнения работы

Напишите программу на языке Kotlin (`Main.kt`), выполняющую следующий сценарий:

#### **Часть 1. Проверка условий через `if-else**`

1. Считайте с консоли параметры состояния Покемона:
* `currentHpInput` (`Int`) — текущий уровень здоровья.
* `energyAttachedInput` (`Int`) — количество прикрепленных карт энергии.


2. Используя **классический `if-else**`, выведите сообщение о боеспособности:
* Если здоровье меньше или равно 0 — напечатайте уведомление о нокауте.
* В противном случае — напечатайте уведомление о том, что Покемон готов к бою.


3. Используя **`if-else` как выражение (Expression)**, сохраните в переменную `attackStatus` (`String`) текстовое описание доступности атаки «Giga Impact» (требуется минимум 3 карты энергии):
* Если энергии достаточно (>= 3) — сохраните текст о готовности к атаке.
* Иначе — сохраните текст с указанием нехватки ресурсов.



#### **Часть 2. Обработка типов и состояний через `when**`

1. Считайте с консоли название карты Тренера (`trainerCardInput`).
2. Используя **классический `when**`, выполните соответствующую печать эффекта:
* `"Potion"` -> напечатать сообщение о лечении на +30 HP.
* `"Professor's Research"` -> напечатать сообщение о доборе 7 карт из колоды.
* `"Switch"` -> напечатать сообщение о замене активного Покемона.
* Для остальных значений -> напечатать сообщение о неизвестной карте.


3. Считайте стихию Покемона (`elementInput`): `"Fire"`, `"Water"`, `"Grass"`, `"Electric"`.
4. Используя **`when` как выражение (Expression) с многострочными блоками `{ }**`, рассчитайте и сохраните коэффициент слабости `weaknessMultiplier` (`Double`):
* Для `"Water"` — выведите текстовый лог о слабости к электричеству и верните `2.0`.
* Для `"Fire"` — выведите текстовый лог о слабости к воде и верните `1.5`.
* Для `"Grass"` — выведите текстовый лог о слабости к огню и верните `1.2`.
* Во всех остальных случаях — выведите лог о базовом коэффициенте и верните `1.0`.



#### **Часть 3. Безаргументный `when` в переменную**

1. Считайте процент здоровья Покемона (`hpPercent` от `0` до `100`).
2. Запишите текстовую категорию состояния в переменную `healthState` (`String`) с помощью **безаргументного `when**`:
* При равенстве 0 -> `"Нокаут"`.
* В диапазоне `1..20` -> `"Критическое состояние"`.
* В диапазоне `21..70` -> `"Поврежден"`.
* Во всех остальных случаях -> `"Отличное состояние"`.

* В программе продемонстрировано применение как классического синтаксиса `if` / `when`, так и синтаксиса выражений с записью результатов в `val`.
* Для многострочных веток `when` верно применены блоки `{ }`, и значением переменной является последняя строка блока.

* Использован безаргументный `when` с диапазоном `in 1..20`.
