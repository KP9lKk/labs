# Лабораторная работа № 4.3

## Тема: Организация циклических процессов с постусловием (цикл do...while) в Pokémon TCG

## 1. Порядок выполнения работы

Напишите программу на языке Kotlin (`Main.kt`), симулирующую механики карточной игры с использованием **исключительно конструкции повторения с постусловием** (`do...while`). В текстах заданий условия сформулированы с расчетом на гарантированное одиночное выполнение действий перед проверкой логического выражения. Использование коллекций (массивов, списков и т.д.) строго запрещено.

---

### Задание 1. Валидация выбора активного Покемона (Стандартный цикл do...while)

1. Попросите пользователя выбрать базового Покемона для старта боя, введя его номер в меню:
   * `1` — Пикачу
   * `2` — Чармандер
   * `3` — Бульбазавр
2. Постройте процесс на основе цикла `do...while`, который **гарантированно запрашивает ввод хотя бы один раз** и повторяет запрос до тех пор, пока пользователь не введет корректный номер (от 1 до 3).
3. На каждом шаге при некорректном вводе выводите сообщение: `"[ОШИБКА] Неверный номер! Попробуйте снова."`
4. После успешного ввода выведите лог: `"[БОЙ] Вы выбрали Покемона №..."`

---

### Задание 2. Механика «Получения урона» до нокаута (Накопление значений)

1. У покемона есть начальное здоровье `hp = 100`.
2. Постройте цикл `do...while`, имитирующий получение урона в конце каждого хода:
   * На каждом шаге запрашивайте у пользователя количество урона, нанесенного противником (целое положительное число).
   * Вычитайте урон из текущего здоровья покемона.
   * Выводите лог: `"[УРОН] Нанесено: ... | Осталось HP: ..."`
3. Цикл должен продолжаться до тех пор, пока `hp` остается **строго больше 0**.
4. По окончании цикла выведите сообщение: `"[НОКАУТ] Покемон потерял сознание и выбывает из боя!"`

---

### Задание 3. Атака «Непрерывный пинок» с фиксацией попаданий (Цикл do...while с условным выходом)

1. Запросите у пользователя лимит энергии для атак (`energyLimit`), например, 4.
2. Постройте цикл `do...while`, который выполняет броски монетки для расчета урона атаки. Каждый бросок стоит 1 единицу энергии.
3. На каждом шаге:
   * Уменьшайте запас энергии на 1.
   * Запрашивайте результат броска с консоли (1 — орёл, 0 — решка).
   * Если выпадает 1 (орёл), выводится лог: `"Бросок №...: Орёл! Урон нанесен. Осталось энергии: ..."`
   * Если выпадает 0 (решка), выводится лог: `"Бросок №...: Решка! Атака сорвалась."`, после чего серия атак завершается **досрочно** (с помощью `break`).
4. Цикл прекращается, если выпала решка ИЛИ если энергия полностью исчерпана (`energyLimit == 0`).

### Задание 4. Взаимный перевод: Словесный алгоритм <-> Код

#### Часть А. Перевод из словесной формы в код

Напишите рабочий фрагмент кода на языке Kotlin, реализующий следующее логическое описание **с обязательным использованием конструкции повторения с постусловием (`do...while`)**:

> *"Считайте с консоли количество карт в руке игрока. После этого выполните добор карт: увеличивайте их количество на 1 и выводите текст 'Взята карта из колоды. Карт в руке: ...' до тех пор, пока общее количество карт в руке не станет минимум 7. По завершении выведите: 'Набор карт завершен!'"*

#### Часть Б. Перевод из кода в словесную форму

Внимательно изучите представленный код на Kotlin и **составьте его понятное описание на естественном русском языке** (в виде пошаговой инструкции или алгоритма действия).

*Требование:* В своем текстовом описании не используйте программистские ключевые слова (такие как *"do"*, *"while"*, *"итерация"*, *"переменная цикла"*, *"булево выражение"*).

```kotlin
var statusDuration = 3
do {
    println("Покемон находится под действием эффекта 'Паралич'. Осталось ходов: $statusDuration")
    statusDuration--
} while (statusDuration > 0)
println("Действие эффекта 'Паралич' закончилось!")
```
