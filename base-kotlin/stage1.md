# Техническое задание: Оцифровка карточки Тренера Pokémon TCG

## 1. Переменные карточки и типы данных

Все характеристики оригинальной карточки **«Леди из Центра Покемонов»** должны храниться в переменных соответствующих типов.

### 1.1. Строковые данные (Вводятся пользователем через `readln()`)

* `cardType` (`String`) — тип карты (`"ТРЕНЕР"`).
* `cardSubtype` (`String`) — подтип карты (`"ПОМОЩНИК"`).
* `cardName` (`String`) — название карты (`"Леди из Центра Покемонов"`).
* `effectText` (`String`) — описание основного эффекта (`"Один из твоих Покемонов излечивает 60 пунктов урона, и с него снимаются все особые состояния."`).
* `ruleText` (`String`) — правило подтипа (`"В свой ход (перед твоей атакой) ты можешь использовать только 1 карту Помощника."`).
* `illustrator` (`String`) — имя художника (`"Megumi Mizutani"`).

### 1.2. Числовые параметры

* `healAmount` (`Int`) — количество излечиваемого урона (`60`).
* `cardNumber` (`Int`) — номер карты в сете (`105`).
* `totalInSet` (`Int`) — всего карт в сете (`106`).

---

## 2. Порядок выполнения работы

1. Запросить у пользователя ввод всех 6 строковых переменных (пункт 1.1) с помощью `print()`, чтобы ввод выполнялся на той же строке.


2. Инициализировать в коде числовые параметры (пункт 1.2).


3. Сформировать и вывести карточку в консоль по эталонному шаблону.



---

## 3. Эталонный формат вывода

```text
======================================================================
[ТРЕНЕР] Леди из Центра Покемонов                          [ПОМОЩНИК]
----------------------------------------------------------------------
Эффект: Один из твоих Покемонов излечивает 60 пунктов
        урона, и с него снимаются все особые состояния.

Правило: В свой ход (перед твоей атакой) ты можешь использовать
         только 1 карту Помощника.
----------------------------------------------------------------------
Илл. Megumi Mizutani                                       105/106 ★
======================================================================

```

---

## 4. Критерии оценки (3-балльная шкала)

### Оценка «5» (Отлично)

* Введены с клавиатуры все 6 строковых переменных (`cardType`, `cardSubtype`, `cardName`, `effectText`, `ruleText`, `illustrator`).


* Все числовые параметры заданы явными целыми типами (`Int` для количества лечения, номера карты и объема сета).


* Приглашения к вводу реализованы через `print()`, обеспечивая ввод на той же строке.


* Вывод карточки полностью соответствует эталонному макету (со сплошными горизонтальными разделителями).


* Для форматирования строк используется строго подстановка `$variable` без конкатенации оператором `+`.



### Оценка «4» (Хорошо)

* Все данные выводятся, программа компилируется и работает без ошибок.


* Присутствуют некритичные недочеты:
* Для организации ввода использован `println()` вместо `print()`.


* Незначительно нарушено выравнивание строк или разделителей в итоговой карточке.


* Использованы неинформативные имена переменных (например, `t1`, `n2`).





### Оценка «3» (Удовлетворительно)

* Программа запускается, но логика нарушена:
* Для числовых характеристик использован тип `String` вместо `Int`.


* Часть строковых переменных зашита прямо в код вместо считывания с клавиатуры.


* При выводе данные путаются местами или выведены не полностью.





### Оценка «2» / Не зачтено

* Программа не компилируется (содержит синтаксические ошибки).


* Код скопирован без понимания, студент не может объяснить назначение объявленных переменных.
