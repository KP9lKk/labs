# Техническое задание на класс `PokemonDeck` (Kotlin)

**Версия:** 1.3  
**Язык:** Kotlin (JVM), стандартная библиотека Kotlin/Java SE.

---

## 1. Назначение

Разработать класс `PokemonDeck`, моделирующий колоду карт Pokémon TCG для учебного/игрового модуля. Класс хранит набор карт, поддерживает перемешивание, взятие верхней карты, просмотр верхней карты, подсчёт оставшихся карт и сброс колоды в исходное состояние.

Полные правила Pokémon TCG, UI, БД, сеть и персистентность **не реализуются**.

---

## 2. Предметная область

**Pokémon TCG** — коллекционная карточная игра. Игрок использует колоду, из которой берёт карты в процессе игры. В упрощённой модели:

- **Карта** — объект с минимальными атрибутами: `id`, `name`, `category`.
- `category` — перечисление `CardCategory` со значениями `POKEMON`, `TRAINER`, `ENERGY`.
- **Колода** — упорядоченный список карт с понятием «верх колоды».
- **Верх колоды** — последний элемент внутреннего списка (`list.last()`).
- Дубликаты карт допускаются.
- Ограничения TCG (60 карт, не более 4 копий по имени и т.п.) **не проверяются**.

---

## 3. Модель карты

```kotlin
enum class CardCategory { POKEMON, TRAINER, ENERGY }

data class Card(
    val id: String,
    val name: String,
    val category: CardCategory
)
```

Дополнительные поля не требуются. `data class` обеспечивает корректные `equals/hashCode/toString`.

---

## 4. Функциональные требования к `PokemonDeck`

### 4.1. Состояние класса

Класс инкапсулирует:

- `private val cards: MutableList<Card>` — текущая колода;
- `private val initialCards: List<Card>` — снимок исходного набора для `reset()`;
- `private val random: Random` — экземпляр `kotlin.random.Random` (с возможностью задать seed).

### 4.2. Публичный API

| Метод | Поведение | Пустая колода |
|---|---|---|
| `fun shuffle()` | Перемешивает текущую колоду. Состав и количество не меняются. | Без эффекта |
| `fun draw(): Card?` | Удаляет и возвращает верхнюю карту. | Возвращает `null` |
| `fun peek(): Card?` | Возвращает верхнюю карту без удаления. | Возвращает `null` |
| `fun remaining(): Int` | Количество оставшихся карт. | `0` |
| `fun isEmpty(): Boolean` | `true`, если карт нет. | `true` |
| `fun reset()` | Восстанавливает исходный набор и исходный порядок. Перемешивание **не** выполняется. | — |

Пустая колода — штатная ситуация, поэтому `draw()`/`peek()` возвращают `null`, а не выбрасывают исключения.

### 4.3. Конструктор

```kotlin
class PokemonDeck(
    cards: List<Card>,
    seed: Int? = null
)
```

- `cards` — исходный набор; копируется во внутренние списки (`toList()`/`toMutableList()`), чтобы внешние изменения не влияли на колоду.
- `seed != null` → `Random(seed)` для детерминированного перемешивания; `seed == null` → `Random.Default`.

### 4.4. Сигнатуры

```kotlin
class PokemonDeck(cards: List<Card>, seed: Int? = null) {
    fun shuffle(): Unit
    fun draw(): Card?
    fun peek(): Card?
    fun remaining(): Int
    fun isEmpty(): Boolean
    fun reset(): Unit
}
```
