# Раздел 5.2. Практикум и списки задач: Множества и операции над ними в Pokémon TCG

## 1. Сводный список ключевых понятий раздела

* **Типы коллекций в Kotlin:**

    * `Set<T>` — неизменяемое (read-only) множество уникальных элементов. Автоматически игнорирует дубликаты.

    * `MutableSet<T>` — изменяемое множество, поддерживающее добавление (`add`), удаление (`remove`) и проверку наличия (`contains`).

    * `HashSet<T>` — реализация множества на основе хеш-таблицы; не гарантирует порядок обхода элементов.

    * `LinkedHashSet<T>` — реализация множества, сохраняющая порядок добавления элементов.

    * `setOf(...)` — создание неизменяемого множества.

    * `mutableSetOf(...)` — создание изменяемого множества.

    * `toSet()` — преобразование коллекции (например, списка) в множество с удалением дубликатов.

* **Основные операции над множествами:**

    * `contains` / `in` — проверка наличия элемента во множестве.

    * `add` — добавление элемента в `MutableSet` (если элемента ещё нет).

    * `remove` — удаление элемента из `MutableSet`.

    * `union` / `+` — объединение двух множеств.

    * `intersect` — пересечение множеств (общие элементы).

    * `subtract` / `-` — разность множеств (элементы первого множества, которых нет во втором).

    * `filter { ... }` — отбор элементов, удовлетворяющих заданному условию.

    * `map { ... }` — преобразование каждого элемента множества в новое значение.

    * `count { ... }` — подсчёт количества элементов, соответствующих условию.

    * `joinToString(...)` — объединение элементов множества в единую строку с разделителями.

    * `sortedBy { ... }` — сортировка элементов по заданному полю или критерию.

    * С помощью `count` посчитайте количество карт, содержащих `"Пикачу"`.

    * С помощью `joinToString` выведите список всех карт тренеров в виде красивой строки.
