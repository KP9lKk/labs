# Инструкция по сдаче лабораторных работ через Gitea

Все лабораторные работы и практические задания сдаются в **один индивидуальный репозиторий**, созданный на основе единого шаблона.

---

## Шаг 1. Первичная настройка Git (выполняется 1 раз)

Откройте терминал (или Git Bash) и укажите ваши реальные имя и фамилию:

```bash
git config --global user.name "Имя Фамилия"
git config --global user.email "your-email@example.com"

```

---

## Шаг 2. Создание репозитория из шаблона

1. Перейдите на сервер Gitea:
👉 **http://31.128.39.10:3000**
2. Авторизуйтесь под своей учетной записью.
3. Откройте шаблонный репозиторий по ссылке:
👉 **http://31.128.39.10:3000/admin/template**
4. Найдить и нажмите кнопку **«Использовать этот шаблон»** (*Use this template*).
5. Заполните параметры нового репозитория:
* **Владелец (Owner):** выберите ваш аккаунт.
* **Имя репозитория (Repository Name):** строго по формату `дисциплина-фамилия`
*(Примеры: `prog-ivanov`, `db-petrov`, `mob-sidorov`)*.
* **Шаблон:** Выберите **admin/template** (*Public*).
* **Элементы шаблона:** Выберите **Содержимое Git (ветвь по умолчанию)** (*Public*).


6. Нажмите кнопку **«Создать репозиторий»**.

---

## Шаг 3. Клонирование репозитория на ПК

1. На странице созданного репозитория скопируйте HTTP-ссылку.
2. Откройте терминал на ПК, перейдите в папку, где храните учебу, и выполните:

```bash
git clone http://31.128.39.10:3000/ВАШ_ЛОГИН/НАЗВАНИЕ_РЕПОЗИТОРИЯ.git

```

3. Перейдите в папку проекта:

```bash
cd НАЗВАНИЕ_РЕПОЗИТОРИЯ

```

---

## Шаг 4. Структура проекта и выполнение работы

Выполняйте работу **строго внутри соответствующей папки**:

```text
works/
├── lab-01/          <- Первая лабораторная работа
│   ├── src/         <- Исходный код (Rider / IntelliJ / Android Studio)
│   ├── screenshots/ <- Скриншоты работы
│   └── README.md    <- Отчет по работе

```

* **Файл `.gitignore` уже настроен**: скомпилированные файлы (`bin/`, `obj/`, `build/`) и настройки IDE (`.idea/`) не попадут в репозиторий автоматически.

---

## Шаг 5. Сохранение и отправка работы на сервер

После завершения работы выполните в терминале внутри папки репозитория 3 команды:

1. **Индексация изменений:**
```bash
git add .

```


2. **Фиксация коммита:**
```bash
git commit -m "feat: выполнена лабораторная работа 1"

```


3. **Отправка на сервер:**
```bash
git push

```
