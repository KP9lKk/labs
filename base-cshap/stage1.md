# Техническое задание: Оцифровка карточки Pokémon TCG

## 1. Переменные карточки и типы данных

Все характеристики оригинальной карточки Пикачу (№ 025) должны храниться в переменных с соответствующими типами:
![Пикачу](images\1aa1466c2680aab783b744e68d91fab8.jpg)

### 1.1. Строковые данные (Вводятся пользователем через `Console.ReadLine()`)

* `stage` (`string`) — стадия развития (`"БАЗОВЫЙ"`).
* `name` (`string`) — имя покемона (`"Пикачу"`).
* `category` (`string`) — вид покемона (`"Мышь"`).
* `attack1Name` (`string`) — название первой атаки (`"Электроудар"`).
* `attack1Desc` (`string`) — эффект первой атаки (`"Брось монету. Если выпал орёл, активный Покемон твоего противника теперь парализован."`).
* `attack2Name` (`string`) — название второй атаки (`"Быстрая Атака"`).
* `attack2Desc` (`string`) — эффект второй атаки (`"Брось монету. Если выпал орёл, эта атака наносит на 10 пунктов урона больше."`).
* `weakness` (`string`) — уязвимость (`"Боевой x2"`).
* `resistance` (`string`) — устойчивость (`"Стальной -20"`).

### 1.2. Числовые и системные параметры (Задаются жестко в коде)

* `hp` (`int`) — очки здоровья (`60`).
* `number` (`int`) — реестровый номер (`25`).
* `height` (`double`) — рост в метрах (`0.4`).
* `weight` (`double`) — вес в килограммах (`6.0`).
* `attack2Damage` (`int`) — базовый урон второй атаки (`20`).
* `retreatCost` (`int`) — стоимость отступления (`1`).

---

## 2. Порядок выполнения работы

1. Запросить у пользователя ввод всех строковых переменных (пункт 1.1) с помощью `Console.Write()`.
2. Инициализировать в коде числовые параметры (пункт 1.2).
3. Очистить консоль (`Console.Clear()`) и вывести карточку по шаблону.

## 4. Критерии оценки (3-балльная шкала)

### Оценка «5» (Отлично)

* Введены с клавиатуры все 9 строковых переменных (`stage`, `name`, `category`, `attack1Name`, `attack1Desc`, `attack2Name`, `attack2Desc`, `weakness`, `resistance`) с полным оригинальным текстом описание эффектов.
* Все числовые параметры заданы явными типами (`int` для ОЖ, номера, урона и отступления; `double` для роста и веса).
* Приглашения к вводу реализованы через `Console.Write()`, обеспечивая ввод на той же строке.
* Вывод карточки полностью соответствует эталонному макету (без боковых граней, со сплошными горизонтальными разделителями).
* Для форматирования строк используется строго интерполяция (`$""`) без конкатенации оператором `+`.

### Оценка «4» (Хорошо)

* Все данные выводятся, программа компилируется и работает без ошибок.
* Присутствуют некритичные недочеты:
* Для организации ввода использован `Console.WriteLine()` вместо `Console.Write()`.
* Незначительно нарушено выравнивание строк или разделителей в итоговой карточке.
* Использованы неинформативные имена переменных (например, `a1`, `t2`).



### Оценка «3» (Удовлетворительно)

* Программа запускается, но логика нарушена:
* Для числовых характеристик использован тип `string` вместо `int`/`double`.
* Часть строковых переменных зашита прямо в код вместо считывания с клавиатуры.
* При выводе данные путаются местами или выведены не полностью.



### Оценка «2» / Не зачтено

* Программа не компилируется (содержит синтаксические ошибки).
* Код скопирован без понимания, студент не может объяснить назначения объявленных переменных.
