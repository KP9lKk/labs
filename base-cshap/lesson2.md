# Лабораторная работа № 2

## БЛОК 1: Ввод данных и преобразование типов (`int.Parse`)

### 1. Теоретические сведения

Все данные, вводимые пользователем через `Console.ReadLine()`, поступают в программу как текстовая строка (`string`). Чтобы использовать эти данные в математических расчётах, их необходимо преобразовать в числовой тип `int` с помощью метода `int.Parse()`.

Синтаксис преобразования:

```csharp
int number = int.Parse(Console.ReadLine());

```

## БЛОК 2: Условные операторы (`if / else` и `switch`)

### 1. Теоретические сведения

Для управления ходом выполнения программы используются условные конструкции:

* **`if / else`** применяется для проверки сложных условий и диапазонов значений (например, проверки уровня здоровья HP).
* **`switch`** удобно использовать для построения консольных меню, где выбор зависит от конкретного введённого значения.

---

### 2. Практические задания

#### Задание 2.1: Проверка состояния покемона в бою (`if / else`)

**Формулировка задачи:** Разработать систему анализа здоровья (HP) покемона во время поединка.

**Техническое задание:**

1. Запросить у пользователя текущее количество HP покемона (целое число).
2. С помощью каскада условных операторов `if / else if / else` определить состояние покемона и вывести соответствующее сообщение:
* **HP $\le$ 0:** *"Покемон потерял сознание! Верните его в покебол."*
* **HP от 1 до 20:** *"Критическое состояние! Срочно используйте зелье!"*
* **HP от 21 до 50:** *"Покемон ранен, будьте осторожны."*
* **HP > 50:** *"Покемон полон сил и готов к бою!"*
