## 1. Краткие теоретические сведения## 1.1. Понятие коллекции и индексации
Коллекция — это структура данных, объединяющая набор элементов в один объект для удобной работы. Доступ к элементам большинства базовых коллекций осуществляется по их индексу — порядковому номеру, который всегда начинается с 0.
## 1.2. Обычные массивы (System.Array)
Массив — это простейшая последовательность элементов строго одного типа с фиксированным размером, который задается один раз при создании и не может быть изменен в процессе работы программы.

// Создание массива строк на 3 элементаstring[] team = new string[3];
team[0] = "Пикачу"; // Запись по индексу 0

## 1.3. Динамические списки (List<T>)
Список (List<T>) — это динамический аналог массива из пространства имен System.Collections.Generic. Он автоматически увеличивает или уменьшает свой размер по мере добавления или удаления элементов.

List<string> inventory = new List<string>();
inventory.Add("Покебол");    // Метод добавления элемента
inventory.Remove("Покебол"); // Метод удаления элемента

## 1.4. Перебор коллекций с помощью foreach
Цикл foreach используется для последовательного чтения элементов коллекции без использования индексов и счетчиков. Внутри этого цикла элементы изменять нельзя.

foreach (string item in inventory)
{
Console.WriteLine(item);
}
