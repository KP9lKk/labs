# Лабораторная работа № 5
## Тема: Функции и методы в C#. Возвращаемые значения и модификаторы параметров (ref, out, in, params)

## 1. Краткие теоретические сведения

## 1.1. Понятие функции (метода)
Метод — это именованный блок кода, который выполняет определенную задачу и может быть вызван из других частей программы. Методы помогают избегать дублирования кода и разбивать сложную логику на понятные шаги.

## 1.2. Граница между возвращающими и не возвращающими значения методами
Все методы в C# четко делятся на две категории в зависимости от того, отдают они результат своей работы обратно в программу или просто выполняют действия на месте.

### 1) Не возвращающие значения методы (`void`)
Если метод выполняет какое-то действие (выводит текст на экран, изменяет состояние, записывает файл) и не должен возвращать никакой результат в вызывающий код, перед его именем указывается ключевое слово **`void`**.
* Внутри такого метода оператор `return` необязателен. Его можно использовать без значения (`return;`) только для досрочного выхода из метода.
* Результат работы такого метода нельзя присвоить переменной.

**Пример использования:**
```csharp
static void ShoutGreeting(string pokemonName)
{
    Console.WriteLine($"[Голос]: {pokemonName} готов к бою!");
    // return не нужен, так как тип метода void
}

// Использование в Main:
ShoutGreeting("Пикачу"); // Просто вызываем метод. Он выполнит вывод на экран.
```

### 2) Возвращающие значения методы (с оператором `return`)
Если метод должен произвести вычисления и отдать результат обратно для дальнейшего использования (например, для записи в переменную), вместо `void` указывается **конкретный тип данных** (`int`, `string`, `double` и т.д.), который метод вернет.
* Внутри такого метода **обязан** присутствовать оператор **`return`**, после которого идет возвращаемое значение или переменная соответствующего типа.
* Как только программа доходит до строки с `return`, метод немедленно завершает свою работу, а значение «улетает» в место вызова.

**Пример использования:**
```csharp
static int CalculateDamage(int power)
{
    int finalDamage = power * 2;
    return finalDamage; // Обязательный возврат значения типа int
}

// Использование в Main:
int currentPower = 40;
// Результат работы метода сохраняем в новую переменную totalDamage
int totalDamage = CalculateDamage(currentPower); 

Console.WriteLine($"Нанесенный урон: {totalDamage}"); // Выведет: Нанесенный урон: 80
```

## 1.3. Модификаторы параметров (ref, out, in)
По умолчанию аргументы передаются в метод **по значению** (создается копия данных, и изменения внутри метода не влияют на внешнюю переменную). Модификаторы позволяют изменить это поведение:

### 1) Модификатор `ref` (передача по ссылке)
Передает переменную по ссылке. Любые изменения переменной внутри метода изменят исходную переменную в вызывающем коде. 
*Важное условие:* Переменная **обязательно должна быть инициализирована** (ей должно быть присвоено начальное значение) до вызова метода.

**Пример использования:**
```csharp
static void LevelUp(ref int level)
{
    level += 1; // Напрямую увеличиваем значение исходной переменной
}

// Использование в Main:
int myPokemonLevel = 5; // Переменная инициализирована
LevelUp(ref myPokemonLevel);

Console.WriteLine(myPokemonLevel); // Выведет: 6 (значение изменилось!)
```

### 2) Модификатор `out` (выходной параметр)
Используется, когда методу нужно вернуть изнутри сразу несколько значений (так как обычный `return` может вернуть только одно). 
*Важное условие:* Переменная **обязательно должна получить значение внутри метода** до его завершения. До вызова метода инициализировать её не нужно (можно объявить прямо в момент вызова).

**Пример использования:**
```csharp
static void GetPokemonStats(out int attack, out int defense)
{
    // Обязаны присвоить значения внутри метода
    attack = 55;
    defense = 40;
}

// Использование в Main:
// Переменные объявляются прямо "на лету" внутри аргументов
GetPokemonStats(out int pokeAttack, out int pokeDefense);

Console.WriteLine($"Атака: {pokeAttack}, Защита: {pokeDefense}"); 
// Выведет: Атака: 55, Защита: 40
```

### 3) Модификатор `in` (входная ссылка)
Передает аргумент по ссылке, но **запрещает его изменение** внутри метода (переменная становится доступна только для чтения). Если вы попытаетесь изменить этот параметр, компилятор выдаст ошибку. Используется для оптимизации производительности при передаче больших объектов и тяжелых структур, чтобы C# не копировал их в памяти.

**Пример использования:**
```csharp
static void PrintArenaRules(in string rulesText)
{
    // rulesText = "Новые правила"; // ОШИБКА КОМПИЛЯЦИИ! Менять in-параметры нельзя.
    Console.WriteLine($"Правила боя: {rulesText}");
}

// Использование в Main:
string currentRules = "Использовать только одного покемона.";
PrintArenaRules(in currentRules); // Выведет правила на экран
```

## 1.4. Ключевое слово params
Модификатор `params` позволяет методу принимать переменное количество аргументов одного типа. Внутри метода эти аргументы упаковываются в обычный массив. Метод может иметь только один `params`-параметр, и он должен быть последним в списке параметров.

```csharp
static void ShowTeam(params string[] pokemons)
{
    // pokemons внутри метода работает как обычный массив
}
```

## Задание 1. Лечение в Покецентре (Использование ref)
**Формулировка задачи:** Реализовать функцию восстановления здоровья покемона, которая напрямую изменяет показатель здоровья переданной переменной.

### Техническое задание:
1. В методе `Main` объявить переменную `int pokemonHP` и присвоить ей значение `20`.
2. Создать метод `HealPokemon`, который принимает параметр здоровья по ссылке с помощью модификатора `ref`. Метод не должен ничего возвращать (тип `void`).
3. Внутри метода увеличить значение здоровья на `80` единиц (до максимальных 100) и вывести сообщение о лечении.
4. Вызвать метод в `Main` и вывести значение `pokemonHP` до и после вызова, чтобы доказать, что исходная переменная изменилась.

### Требуемый формат вывода:
```
=== ПОКЕЦЕНТР: ЛЕЧЕНИЕ ===
Здоровье до лечения: 20 HP.
[Покецентр] Покемон полностью здоров! Восстановлено 80 HP.
Здоровье после лечения: 100 HP.
```

## Задание 2. Поиск дикого покемона в высокой траве (Использование out)
**Формулировка задачи:** Реализовать функцию исследования локации, которая возвращает случайное имя встреченного покемона и его уровень через `out`-параметры.

### Техническое задание:
1. Создать метод `SearchBushes`, который возвращает результаты через ключевые слова `out`: `out string foundPokemon` (имя) и `out int pokemonLevel` (уровень). Сам метод должен иметь тип возвращаемого значения `void`.
2. Внутри метода с помощью класса `Random` сымитировать случайный выбор: имя должно стать `"Пикачу"`, а уровень — случайным числом от 1 до 15.
3. В методе `Main` вызвать `SearchBushes`, передав в него новые (неинициализированные) переменные, и красиво вывести результат на экран.

### Требуемый формат вывода:
```
=== ИССЛЕДОВАНИЕ ЛОКАЦИИ ===
Вы зашли в высокую траву...
Шорох! Из кустов появляется дикий Пикачу (Уровень: 7)!
```

## Задание 3. Турнир чемпионов (Использование params и in)
**Формулировка задачи:** Создать систему регистрации участников турнира, способную принимать любое количество покемонов за раз, используя фиксированный коэффициент сложности стадиона.

### Техническое задание:
1. Создать метод `RegisterTournament` (тип `void`), который принимает неизменяемый коэффициент сложности `in double difficulty` и массив покемонов-участников `params string[] participants`.
2. Внутри метода попытаться изменить значение `difficulty` (убедиться, что компилятор выдает ошибку, затем закомментировать или удалить эту строку).
3. С помощью цикла вывести на экран весь список зарегистрированных покемонов.
4. Вызвать этот метод в `Main` дважды: первый раз передав 2 покемонов, второй раз — 4 покемонов напрямую через запятую.

### Требуемый формат вывода:

Коэффициент стадиона: 1,5
Список участников:
