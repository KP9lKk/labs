## 1. Краткие теоретические сведения

### 1.1. Класс — это чертёж, объект — экземпляр
Класс в C# — это не просто «папка с переменными». Это шаблон, по которому создаются объекты. Если класс — это шаблон покемона в Покедексе, то объект — это твой конкретный Пикачу с именем, уровнем и HP, который сейчас бегает по траве.

```csharp
class Pokemon
{
    // поля, свойства, методы
}

Pokemon pika = new Pokemon("Пикачу", 5, 100);
```

`Pokemon` — класс (тип данных). `pika` — объект (экземпляр класса).

### 1.2. Поля, свойства и методы
- **Поля** — переменные внутри класса. Обычно делаются `private`, чтобы никто извне не лез во внутренности покемона.
- **Свойства** — контролируемый доступ к полям. Позволяют проверить значение перед записью.
- **Методы** — действия, которые умеет выполнять покемон (атаковать, лечиться, повышать уровень).

```csharp
class Pokemon
{
    private int hp;

    public int HP
    {
        get { return hp; }
        set
        {
            if (value < 0) hp = 0;
            else if (value > 100) hp = 100;
            else hp = value;
        }
    }

    public void ShowInfo()
    {
        Console.WriteLine($"HP: {HP}");
    }
}
```

### 1.3. Конструкторы и `this`
Конструктор — это метод, который вызывается при создании объекта через `new`. Его имя совпадает с именем класса, и у него нет возвращаемого типа. По сути, это момент «рождения» покемона.

```csharp
class Pokemon
{
    public string Name;
    public int Level;

    public Pokemon(string name, int level)
    {
        Name = name;
        Level = level;
    }
}
```

Если параметр конструктора называется так же, как поле, используй `this`:

```csharp
public Pokemon(string name, int level)
{
    this.Name = name;
    this.Level = level;
}
```

Конструкторы можно перегружать: сделать один с параметрами, другой без (например, «яйцо» — покемон без имени и с нулевым уровнем).

### 1.4. Инкапсуляция: чтобы покемона не сломали
Если все поля сделать `public`, любой желающий сможет поставить HP = -9999 или уровень = 100500. Инкапсуляция решает это: поля `private`, а доступ через свойства с проверками. Покемон сам следит за своим состоянием.

```csharp
private int level;

public int Level
{
    get { return level; }
    set
    {
        if (value < 1) level = 1;
        else if (value > 100) level = 100;
        else level = value;
    }
}
```

### 1.5. `static`: общее для всех покемонов
`static` поле или свойство принадлежит не объекту, а всему классу. Например, счётчик всех созданных покемонов — он же один на всю программу, как счётчик в Покедексе.

```csharp
class Pokemon
{
    public static int Count { get; private set; } = 0;

    public Pokemon(string name)
    {
        Count++;
    }
}
```

Теперь `Pokemon.Count` покажет, сколько всего покемонов было создано.

## Задание 1. Регистрируем покемона в Покедексе

**Формулировка задачи:** Создать класс `Pokemon`, который описывает покемона и умеет выводить информацию о себе.

### Техническое задание:
1. Создай класс `Pokemon`.
2. Внутри класса должно быть **минимум 3 приватных поля**:
   - `name` (имя покемона);
   - `level` (уровень);
   - `hp` (здоровье).
3. Создай **3 публичных свойства** с `get` и `set`: `Name`, `Level`, `HP`.
4. Добавь **конструктор с параметрами**, чтобы покемон сразу создавался с именем, уровнем и HP.
5. Добавь метод `ShowInfo()`, который выводит всю информацию о покемоне.
6. В `Main` создай **2 покемона** через `new` и вызови у них метод `ShowInfo()`.

### Требуемый формат вывода:
```
=== ПОКЕДЕКС ===
1. Имя: Пикачу, Уровень: 5, HP: 100
2. Имя: Сквиртл, Уровень: 7, HP: 90
```

**Свобода:** можешь добавить тип покемона (электрический, водный, огненный), кличку, дату поимки — что угодно. Можешь сделать вывод красивее (рамки, эмодзи, цвета через `Console.ForegroundColor`). Главное — минимум из ТЗ.

## Задание 2. Инкапсуляция: чтобы покемона не сломали

**Формулировка задачи:** Закроем внутренности покемона и дадим доступ только через свойства с проверками. Покемон сам должен защищать свои данные от некорректных значений.

### Техническое задание:
1. Убедись, что поля класса `Pokemon` стали `private`.
2. В свойствах добавь проверки:
   - `HP` не может быть меньше 0 и больше 100;
   - `Level` не может быть меньше 1 и больше 100;
   - `Name` не может быть пустой строкой (если пришло пустое — ставь `"Безымянный"`).
3. Добавь методы, которые меняют состояние покемона:
   - `TakeDamage(int damage)` — уменьшает HP, но не ниже 0;
   - `Heal()` — восстанавливает HP до 100.
4. Добавь **перегрузку конструктора**: например, конструктор без параметров, который создаёт «яйцо» — безымянного покемона 1 уровня с 100 HP.
5. В `Main` покажи:
   - создай покемона;
   - попробуй присвоить свойству `HP` некорректное значение (`-50`);
   - вызови `TakeDamage(30)`, потом `Heal()`;
   - выведи результат после каждого шага.

### Требуемый формат вывода:
```
=== ПРОВЕРКА ИНКАПСУЛЯЦИИ ===
Попытка установить HP = -50...
Текущее HP: 0 (защита сработала)
Покемон получил 30 урона. HP: 70
Покемон вылечился. HP: 100
```

**Свобода:** можешь сделать `TakeDamage` с рандомным уроном или добавить проверку, что покемон не может лечиться, если он уже полностью здоров. Можешь добавить метод `LevelUp()`, который повышает уровень, но не выше 100.

## Задание 3. Битва покемонов и Покедекс-счётчик

**Формулировка задачи:** Добавим подсчёт всех созданных покемонов и научим их сражаться друг с другом. Метод взаимодействия должен принимать **другой объект** того же класса.

### Техническое задание:
1. Добавь `static` свойство `Count`, которое увеличивается в каждом конструкторе:
   ```csharp
   public static int Count { get; private set; } = 0;
   ```
2. Добавь метод `Battle(Pokemon enemy)`, который:
   - выводит сообщение о начале боя;
   - сравнивает уровни (или HP) двух покемонов;
   - выводит победителя и его оставшееся HP;
   - **изменяет** HP проигравшего покемона (например, победитель наносит урон, равный своему уровню).
3. В `Main` создай **минимум 3 покемона**.
4. Выведи общее количество созданных покемонов через `Pokemon.Count`.
5. Вызови `Battle` для двух покемонов.
6. После боя выведи состояние проигравшего — HP должно измениться.

### Требуемый формат вывода:
```
=== ПОКЕДЕКС: СТАТИСТИКА ===
Создано покемонов: 3

=== БИТВА ===
Пикачу (Ур. 5, HP 100) против Сквиртл (Ур. 7, HP 90)
Сквиртл побеждает! Пикачу теряет 7 HP.
Победитель: Сквиртл. Осталось HP: 90
Побеждённый: Пикачу. Осталось HP: 93
```

**Свобода:** можешь сделать бой случайным (кто победит — решает `Random`), добавить ничью, добавить тип покемона и учитывать преимущество типа (водный бьёт огненного сильнее). Можешь сделать так, чтобы победитель повышал уровень. `static Count` и метод `Battle(Pokemon enemy)` обязательны — остальное на твой вкус.
