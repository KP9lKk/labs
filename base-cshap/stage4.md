# Техническое задание: Командная дуэль Pokémon TCG (Итоговая сборка)

## 1. Контекст и связь с предыдущими частями

Данная работа — **итоговая**, объединяющая материал всех предыдущих стадий:

* **Часть 1** — оцифровка карточки покемона: переменные, типы данных, интерполяция строк, форматированный вывод.
* **Часть 2** — механика атак: `int.Parse`, условные операторы `if / else` и конструкция `switch`.
* **Часть 3** — игровой цикл дуэли: циклы `for`, `while`, `do-while`, операторы `break` / `continue`.
* **Часть 4** — коллекции: массивы фиксированного размера, динамические списки `List<T>` и перебор через `foreach`.

Главное отличие от Части 3: теперь тренер управляет **не одним покемоном, а целой командой**, состав которой хранится в массиве, а предметы инвентаря — в динамическом списке. Дуэль продолжается, пока живы покемоны в командах обеих сторон.

---

## 2. Переменные и структуры данных

### 2.1. Команда игрока (Массив `string[]`)

* `activeTeam` (`string[]`) — массив строго на **3 элемента** с именами покемонов команды. Заполняется с клавиатуры через цикл `for`.
* `currentPokemonIndex` (`int`) — индекс активного (текущего) покемона в бою (начальное значение: `0`).

### 2.2. Характеристики активного покемона (Считываются от пользователя, как в Части 3)

* `stage` (`string`) — стадия развития (`"БАЗОВЫЙ"`).
* `name` (`string`) — имя покемона (должно совпадать с первым элементом массива).
* `category` (`string`) — вид покемона.
* `hp` (`int`) — очки здоровья активного покемона (`int.Parse`).
* `attack1Name`, `attack1Desc` (`string`) — название и описание 1-й атаки.
* `attack1BaseDamage` (`int`) — базовый урон 1-й атаки (`int.Parse`).
* `attack2Name`, `attack2Desc` (`string`) — название и описание 2-й атаки.
* `attack2BaseDamage` (`int`) — базовый урон 2-й атаки (`int.Parse`).
* `weakness` (`string`) — тип уязвимости (`"Водный x2"`).
* `resistance` (`string`) — тип устойчивости (`"Травяной -20"`).

### 2.3. Инвентарь тренера (Список `List<string>`)

* `backpack` (`List<string>`) — динамический список предметов. При старте содержит: `"Зелье HP"`, `"Покебол"`, `"Антидот"`.
* `hasHealingItem` (`bool`) — флаг наличия в сумке лечащего предмета (`"Зелье HP"`).

### 2.4. Враг и параметры боя (Задаются в коде)

* `enemyTeam` (`string[]`) — массив противников: `{ "Булбазавр", "Сквиртл", "Коффинг" }`.
* `enemyIndex` (`int`) — индекс текущего противника (начальное значение: `0`).
* `enemyHp` (`int`) — очки здоровья текущего противника (`70`).
* `enemyBaseDamage` (`int`) — базовый урон противника (`15`).
* `roundNumber` (`int`) — номер текущего раунда (`1`).
* `actionChoice` (`int`) — выбранное действие (`1`, `2` или `3`).
* `isEnemyDebuffed` (`bool`) — флаг контроля над противником.

## 3. Порядок выполнения и архитектура программы

### ЭТАП 1: Регистрация команды (Массивы)

1. Вывести заголовок `"=== РЕГИСТРАЦИЯ КОМАНДЫ ==="`.
2. С помощью цикла `for` запросить у пользователя имена 3-х покемонов и сохранить их в массив `activeTeam` по индексам `0..2`.
3. Вывести итоговый состав команды с нумерацией, обращаясь к элементам массива по индексам.

### ЭТАП 2: Инвентарь тренера (`List<T>`)

1. Создать список `backpack` и добавить в него три базовых предмета через `.Add()`.
2. Вывести количество предметов через свойство `.Count`.
3. Удалить предмет `"Покебол"` методом `.Remove()` и вывести обновлённое количество.
4. Перебрать оставшиеся предметы циклом `foreach`, выводя строку `$"[Предмет] -> {item}"` для каждой вещи.

### ЭТАП 3: Ввод характеристик и отрисовка карточки (Часть 1)

1. Запросить все текстовые и числовые характеристики **первого** покемона из команды (переменные из п. 2.2). Имя должно совпадать с `activeTeam[0]`.
2. Очистить консоль (`Console.Clear()`) и вывести отформатированную карточку по макету из Части 1 с подстановкой всех введённых переменных.

### ЭТАП 4: Предстартовый отсчёт (Цикл `for`)

1. Вывести обратный отсчёт от 3 до 1 через цикл `for`.
2. Вывести строку старта с составами обеих команд:
   `$"=== СТАРТ КОМАНДНОЙ ДУЭЛИ: [{string.Join(", ", activeTeam)}] VS [{string.Join(", ", enemyTeam)}] ==="`.

### ЭТАП 5: Игровой цикл командной дуэли (`while` + `do-while`)

1. Главный цикл: `while (hp > 0 && enemyIndex < enemyTeam.Length)`.
2. На каждом шаге цикла:
   * Вывести `$"--- Раунд {roundNumber} | {name} VS {enemyTeam[enemyIndex]} ---"`.
   * **Валидация выбора (цикл `do-while`):** запрашивать действие до корректного ввода:
     * `1` — `attack1Name`, `2` — `attack2Name`, `3` — использовать `"Зелье HP"` из инвентаря.
   * **Действие 3 (Инвентарь):** если в `backpack` ещё есть `"Зелье HP"` (проверка через `.Contains()`), восстановить `+20` HP, удалить предмет методом `.Remove()`, вывести `$"Результат: Зелье HP использовано! Восстановлено 20 HP."` и перейти к ходу противника через `continue`. Если предмета нет — вывести сообщение об отсутствии и повторить запрос действия.
   * **Ход игрока:** атака 1 и атака 2 обрабатываются по правилам Части 3 (запрос успешности спецэффекта `1/0`, расчёт урона через `if / else`, флаг `isEnemyDebuffed`).
   * **Проверка нокаута противника:** при `enemyHp <= 0` вывести `$"{enemyTeam[enemyIndex]} нокаутирован!"`. Если это был **не последний** покемон противника — увеличить `enemyIndex`, сбросить `enemyHp = 70` и продолжить бой (`continue`); иначе — `break`.
   * **Ход противника:** расчёт входящего урона через `switch` (Уязвимость x2 / Устойчивость -20 / Обычный тип) по правилам Части 3.
   * Вывести итог раунда и увеличить `roundNumber`.

### ЭТАП 6: Подведение итогов (`foreach`)

1. Вывести `"=== ДУЭЛЬ ОКОНЧЕНА ==="` и победителя через `if / else`.
2. Перебрать массив `activeTeam` циклом `foreach` и вывести для каждого покемона строку-награду: `$"{pokemon} получает опыт за участие в дуэли!"`.

## 5. Критерии оценки (3-балльная шкала)

### Оценка «5» (Отлично)

* Команда игрока и команда противника хранятся в массивах (`string[]`), инвентарь — в `List<string>`; продемонстрирована разница синтаксиса и области применения.
* Перебор инвентаря и итоговой награды выполнен строго через `foreach` без ручных индексов; регистрация команды — через `for` по индексам.
* Корректно применены три типа циклов (`for`, `do-while` валидация меню, `while` главный цикл боя), а также `if / else`, `switch`, `break` и `continue`.
* Логика командной дуэли работает полностью: смена противника после нокаута, использование предмета из списка с реальным удалением через `.Remove()`.
* Консольный вывод соответствует эталонному макету, вся динамика (имена, урон, HP) подставляется из переменных через интерполяцию.

### Оценка «4» (Хорошо)

* Код компилируется и дуэль проходит от начала до конца.
* Присутствуют некритичные недочеты:
  * Для перебора списка вместо `foreach` применён обычный `for` со счётчиком.
  * После нокаута противника не происходит смена на следующего (бой завершается досрочно).
  * Предмет «Зелье HP» восстанавливает HP, но не удаляется из списка.
  * Нарушено текстовое форматирование вывода (текст слипается, отсутствуют разделители).

### Оценка «3» (Удовлетворительно)

* Корректно выполнены только регистрация команды (массив) и инвентарь (`List<T>`), а игровой цикл боя работает не полноценно (проходит один раунд или использует зашитые данные).
* **ИЛИ** элементы коллекций добавляются, но удаление или вывод на экран не работают / вызывают падение программы.

### Оценка «2» / Не зачтено

* Программа не компилируется или содержит синтаксические ошибки.
* Студент не может объяснить разницу между массивом и списком, назначение методов `.Add()` / `.Remove()`, а также работу циклов из предыдущих частей.
