---

## 1. Краткие теоретические сведения

### 1.1. Переменные и типы данных
**Переменная** — поименованная область оперативной памяти, предназначенная для хранения данных определенного типа. 

В C# используется статическая типизация. Синтаксис объявления переменной:
```csharp
[тип_данных] [идентификатор] = [значение];

```

Основные базовые типы:

* `string` — текстовые строки в двойных кавычках.
* `int` — 32-разрядные целые числа со знаком.
* `double` — вещественные числа с плавающей запятой двойной точности.
* `bool` — логический тип, принимающий значения `true` или `false`.

### 1.2. Консольный ввод/вывод

Для взаимодействия с консолью используется системный класс `Console`:

* `Console.WriteLine()` — выводит строковое значение с последующим переходом на новую строку.
* `Console.Write()` — выводит строковое значение без перехода на новую строку.
* `Console.ReadLine()` — приостанавливает выполнение программы и считывает введенную пользователем строку до нажатия клавиши Enter. Возвращает значение типа `string`.

Для удобного форматирования вывода применяется **интерполяция строк**:

```csharp
string title = "Параметр";
int val = 10;
Console.WriteLine($"Название: {title}, Значение: {val}");

```

## 2. Порядок выполнения работы

Работа состоит из двух последовательных этапов. Все задания выполняются в рамках одного консольного проекта в файле `Program.cs`.

---

### Задание 1. Объявление переменных и статический вывод данных

**Формулировка задачи:** Создать переменные, описывающие характеристики объекта, и выдать сформированную структуру данных в консоль.

#### Техническое задание:

1. Объявить и инициализировать в коде следующие переменные:
* `pokemonName` (тип `string`) — значение: `"Чармандер"`.
* `elementType` (тип `string`) — значение: `"Огонь"`.
* `level` (тип `int`) — значение: `1`.
* `hp` (тип `int`) — значение: `95`.


2. Сформировать консольный вывод информации с использованием механизма интерполяции строк (`$""`).

#### Требуемый формат вывода:

```text
=== БАЗА ДАННЫХ ПОКЕМОНОВ ===
Покемон: Чармандер
Стихия: Огонь
Уровень: 1 | HP: 95

```

---

### Задание 2. Интерактивный ввод и динамическое формирование документов

**Формулировка задачи:** Модифицировать алгоритм для обеспечения ввода данных пользователем с клавиатуры и динамической генерации итогового паспорта объекта.

#### Техническое задание:

1. Реализовать последовательный запрос параметров у пользователя:
* Имя тренера (`trainerName`) — тип `string`.
* Имя покемона (`pokemonName`) — тип `string`.
* Тип стихии (`elementType`) — тип `string`.
* Название региона (`regionName`) — тип `string`.


2. Для организации приглашений к вводу использовать метод `Console.Write()`.
3. Считать введенные значения с помощью `Console.ReadLine()`.
4. Вывести итоговый паспорт объекта с использованием форматированного вывода.

#### Требуемый формат диалога и вывода:

```text
Введите имя тренера: Эш
Введите имя покемона: Булбазавр
Введите стихию: Трава
Введите регион: Канто

****************************************
ПАСПОРТ ПОКЕМОНА
Тренер: Эш (Регион: Канто)
Покемон: Булбазавр [Стихия: Трава]
****************************************

```
