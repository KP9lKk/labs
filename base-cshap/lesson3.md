## 1. Краткие теоретические сведения

### 1.1. Циклические конструкции

**Цикл** — управляющая конструкция, позволяющая выполнять один и тот же блок кода многократно до тех пор, пока истинно определённое условие.

В C# используются следующие основные виды циклов:

* `for` (со счётчиком) — используется, когда количество итераций известно заранее.
```csharp
for (int i = 0; i < count; i++)
{
    // Код цикла
}

```


* `do-while` (с постусловием) — проверяет условие *после* выполнения тела цикла. Гарантирует хотя бы однократное выполнение кода.
```csharp
do
{
    // Код, выполняемый хотя бы один раз
} while (условие);

```


* `while` (с предусловием) — проверяет условие *до* выполнения тела цикла. Если условие изначально ложно, цикл не выполнится ни разу.
```csharp
while (условие)
{
    // Код, выполняемый на каждой итерации
}

```



### 1.2. Управление итерациями и бесконечные циклы

* `break` — оператор, который немедленно прерывает выполнение цикла и передаёт управление коду за его пределами.
* `continue` — оператор, который пропускает оставшуюся часть текущей итерации и переходит к следующей проверке условия.
* `while (true)` — бесконечный цикл, который выполняется до тех пор, пока внутри него не сработает оператор `break`. Используется для создания **игрового цикла (Game Loop)**.

### Задание 1. Предстартовая подготовка: Отсчёт и обратный отсчёт (`for`)

**Формулировка задачи:** Реализовать обратный отсчёт перед началом боя и вывод информации о готовности арены с помощью цикла со счётчиком `for`.

#### Техническое задание:

1. С помощью цикла `for` вывести обратный отсчёт перед стартом поединка от 3 до 1.
2. Вывести текстовое сообщение о начале боя.
3. Объявить и инициализировать в коде характеристики покемонов:

* `pokemon1Name` (тип `string`) — значение: `"Пикачу"`.
* `pokemon1Hp` (тип `int`) — значение: `50`.
* `pokemon1Attack` (тип `int`) — значение: `12`.
* `pokemon2Name` (тип `string`) — значение: `"Булбазавр"`.
* `pokemon2Hp` (тип `int`) — значение: `55`.
* `pokemon2Attack` (тип `int`) — значение: `10`.
* `roundNumber` (тип `int`) — счётчик раундов, начальное значение: `1`.

#### Требуемый формат вывода:

```text
Приготовьтесь!
3...
2...
1...
=== БОЙ НАЧИНАЕТСЯ ===
Пикачу (HP: 50 | Атака: 12) VS Булбазавр (HP: 55 | Атака: 10)

```

### Задание 2. Интерактивный запрос выбора действия (`do-while`)

**Формулировка задачи:** Реализовать гарантированный первый запрос готовности тренера к бою с проверкой ввода с помощью цикла `do-while`.

#### Техническое задание:

1. Запросить у пользователя подтверждение старта боя (`1` — Начать бой, `0` — Сдаться).
2. С помощью цикла `do-while` производить повторный запрос ввода до тех пор, пока пользователь не введёт корректную команду (`1` или `0`).
3. Для ввода и преобразования использовать `int.Parse(Console.ReadLine())`.
4. Если пользователь ввёл `0`, вывести сообщение `"Вы отменили бой!"` и завершить программу.

#### Требуемый формат диалога:

```text
Готовы начать бой? (1 - Да, 0 - Нет): 5
Некорректная команда! Попробуйте снова.
```

### Задание 3. Реализация игрового цикла пошагового боя (`while`)

**Формулировка задачи:** Создать циклический алгоритм поочерёдного обмена ударами между покемонами до тех пор, пока HP одного из участников не опустится до нуля или ниже.

#### Техническое задание:

1. Написать цикл `while`, который продолжается до тех пор, пока оба покемона живы (`pokemon1Hp > 0 && pokemon2Hp > 0`).
2. На каждом шаге цикла (в раунде):

* Вывести номер текущего раунда.
* **Ход Покемона 1:** Вычесть урон `pokemon1Attack` из `pokemon2Hp`. Вывести сообщение об атаке.
* **Проверка:** Если `pokemon2Hp <= 0`, установить `pokemon2Hp = 0`, вывести сообщение о нокауте и досрочно завершить цикл с помощью оператора `break`.
* **Ход Покемона 2:** Вычесть урон `pokemon2Attack` из `pokemon1Hp`. Вывести сообщение об атаке.
* **Проверка:** Если `pokemon1Hp <= 0`, установить `pokemon1Hp = 0`, вывести сообщение о нокауте и досрочно завершить цикл с помощью оператора `break`.
* Вывести остаток HP у обоих участников на конец раунда и увеличить `roundNumber` на 1.

3. За пределами цикла определить победителя с помощью условного оператора `if / else` и вывести итоговое сообщение.

#### Требуемый формат диалога и вывода:

