# Базовые задания по LINQ для модели данных «Покемоны»

Ниже приведены практические задания по языку LINQ на основе модели данных PokeAPI. Предполагается, что работа выполняется с контекстом Entity Framework Core (`dbContext`), содержащим коллекции `Pokemons`, `Types`, `Abilities`, `Stats` и соответствующие связующие сущности.

---

## Уровень 1: Фильтрация, сортировка и проекция

### Задание 1.1. Самый тяжелый покемон
Найдите покемона с максимальным весом (`Weight`). Выведите его имя (`Name`) и вес.
* **Используемые методы:** `OrderByDescending`, `FirstOrDefault` (или `MaxBy`).

### Задание 1.2. Список легких покемонов
Получите список имен всех покемонов, у которых рост (`Height`) меньше 10 дециметров, отсортированный по алфавиту.
* **Используемые методы:** `Where`, `OrderBy`, `Select`, `ToList`.

### Задание 1.3. Средний базовый опыт
Рассчитайте среднее значение базового опыта (`BaseExperience`) среди всех покемонов в базе данных.
* **Используемые методы:** `Average`.

---

## Уровень 2: Фильтрация по связанным сущностям (Many-to-Many)

### Задание 2.1. Покемоны конкретного типа
Найдите всех покемонов, у которых основной тип (слот №1, `Slot == 1`) — `"Fire"`. Выберите только их имена.
* **Используемые методы:** `Where`, `Any` (или навигация через `PokemonTypes`), `Select`.

### Задание 2.2. Покемоны со скрытыми способностями
Получите список покемонов, обладающих хотя бы одной редкой/скрытой способностью (`IsHidden == true`).
* **Используемые методы:** `Where`, `Any`.

### Задание 2.3. Двухтипные покемоны
Найдите всех покемонов, у которых присутствуют сразу два типа (количество записей в `PokemonTypes` равно 2).
* **Используемые методы:** `Where`, `Count`.

---

## Уровень 3: Агрегация, группировка и сложные выборки

### Задание 3.1. Топ-3 покемона по атаке
Выведите топ-3 покемонов с самым высоким значением базовой характеристики (`BaseStat`) для параметра `"Attack"`. На выходе сформируйте анонимный объект с именем покемона и значением атаки.
* **Используемые методы:** `Where`, `OrderByDescending`, `Take`, `Select`.

### Задание 3.2. Группировка по количеству типов
Сгруппируйте покемонов по количеству имеющихся у них типов (1 тип или 2 типа) и посчитайте количество покемонов в каждой группе.
* **Используемые методы:** `GroupBy`, `Select`, `Count`.

### Задание 3.3. Комплексная карточка покемона
Для каждого покемона сформируйте анонимный объект со следующей структурой:
* `Name` — имя покемона.
* `Types` — список названий всех его типов.
* `AbilitiesCount` — общее количество его способностей.
* `TotalStats` — сумма всех его базовых характеристик (`BaseStat`).
* **Используемые методы:** `Select`, `Sum`, `Count`, проекция навигационных свойств.
